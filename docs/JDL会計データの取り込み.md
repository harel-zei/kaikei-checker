# JDL会計データの取り込み

JDL会計から出力したCSVをそのままアップロードできます。ファイル名の変更や
Excelでの加工は不要です（加工するとかえって読めなくなります）。

## アップロードするファイル

| ファイル | 用途 | 必須 |
|---|---|---|
| 仕訳一覧（当期） | チェック対象の仕訳 | ◯ |
| 合計残高試算表（全科目）（当期） | 期首残高 | 推奨 |
| 合計残高試算表（全科目補助別）（当期） | 補助科目別の期首残高 | 推奨 |
| 仕訳一覧（前期） | 前年比較 | 任意 |
| 合計残高試算表（前期） | 前期末残高の補完 | 任意 |

当期・前期の判別はファイル名ではなく、CSV先頭の `＜決算年月日＞` で自動判定します。
6ファイルまとめてドラッグ＆ドロップして構いません。

## JDL固有の扱い

### 科目名の切り詰め
JDLは科目名を8バイト（全角4文字）で書き出すため、`短期借入金` は `短期借入`、
`広告宣伝費` は `広告宣伝` になります。このままだとチェックが科目を認識できないため、
標準的な勘定科目については取り込み時に正式名称へ復元しています
（対応表: `backend/parsers/jdl_parser.py` の `_TRUNCATED_ACCOUNTS`）。

顧問先独自の科目名（`ＴＶ制作`、`スポンサ` など）は勝手に書き換えず、そのまま扱います。
`減価償却` のように貸借（減価償却累計額）と損益（減価償却費）で意味が変わるものは、
科目コードが600未満か以上かで判別します。

**対応表に無い標準科目で指摘が出ない場合は、`_TRUNCATED_ACCOUNTS` に1行足してください。**

### 13月（決算整理仕訳）
JDLは決算整理仕訳の日付を `13月` で表します（例: `61330`）。カレンダー上は存在しない
ため、`＜決算年月日＞` の日付に寄せて取り込みます。寄せないとこれらの仕訳が
日付なしとして全チェックから漏れます。

### 課税区分
JDLは「課区（仕入対課税売上 等）」と「税区（税率１０％ 等）」が別の列に分かれています。
チェック側は1つの税区分文字列を見るため、取り込み時に両者を連結し、
全角の税率表記（`１０％`）を半角（`10%`）に正規化しています。

### 諸口
複合仕訳は科目コード999「諸口」を経由した複数行に分解されています。
諸口を含む行もそのまま取り込みます（諸口は借方・貸方で相殺されるため、
科目別の集計値は正しくなります）。

## 文字コード
JDLの出力は cp932（Shift-JIS）です。アップロード時に自動判定するので指定は不要です。
