# チェック論点一覧（現行の全チェックと判定条件）

会計データチェッカーが現在実施している全チェックの整理です。
「何を担保するか」の観点で4つに分類し、各チェックの**判定条件・必要なデータ・限界（拾えないもの）**を明記しています。
精度調整の相談やチェック追加の検討は、この表を土台にしてください。

最終更新: 2026-07-31（優先度B・C実装済み。優先度Aは実例の蓄積に合わせて追加予定）

---

## A. 網羅性 ― 「あるべき計上が無い」を見つける

| ID | 論点 | 判定条件 | 限界・注意 |
|---|---|---|---|
| 1-1 | 定例費用の発生漏れ | 固定リスト科目（地代家賃・賃借料・リース料・減価償却費・賞与引当金・退職給付費用・法定福利費）が計上ゼロの月を検出 | リストにない科目は対象外（→6-1が補完） |
| 1-4 | 補助科目単位の当月漏れ | 固定リスト科目（賃借料・地代家賃・リース料・保険料・支払手数料・水道光熱費・通信費・諸会費）で、直前3ヶ月連続計上の補助科目が**直近月だけ**無い | 直近月限定（→6-2/6-4が全期間を補完） |
| 6-1 | 定期費用の欠落（科目） | データから自動判定：全月の75%以上に計上・月額1,000円以上の損益/製造原価科目が欠落した月 | 4ヶ月以上のデータが必要。1-1担当科目は重複防止のため対象外 |
| 6-2 | 定期取引の欠落（補助科目） | 科目自体は在る月に、毎月あった取引先/契約（補助科目なし含む）だけが無い | 同上 |
| 6-3 | 定期取引の欠落（摘要・金額） | 補助科目が無くても、摘要の正規化キーまたは「科目×ほぼ同額（±10円 or 0.2%）」で定期取引を識別し欠落を検出 | 金額が毎月大きく変わる取引は対象外（誤検知防止）。月内に同額が多発する取引も対象外 |
| 6-4 | 定期取引の途絶 | 期の途中まで毎月あった取引が、直近2ヶ月以上連続で無い（解約か漏れかの確認喚起） | 直近1ヶ月だけの欠落は1-4が担当 |
| 1-2 | 期間帰属（月末曜日ズレ） | 月末対象科目で、当月末（28日以降）に仕訳が無く翌月初（1〜3日）に有る | 対象は法定福利費・給料手当・役員報酬・賞与・地代家賃 |
| PL | 粗利率の月次変動 | 月次粗利率が期中平均±2σを超過 | 棚卸を決算月のみ計上している場合は簡易値 |
| 1-3 | 売上・仕入等の急変 | 前3ヶ月平均比 20%以下に急減 or 3倍以上に急増（差額10万円超） | 対象キーワード: 売上・仕入・給料・外注 |
| PL | 前月比の急変 | 給与・外注費・地代家賃が前月比±50%超かつ差額5万円超 | 変動が本来大きい科目（広告費等）は対象外 |
| 前年比 | 前年同期比較 | 当期入力済み期間と前期同月範囲の**累計**を比較し、±20%かつ差額20万円以上 | 前期仕訳帳のアップロードが必要 |

## B. 残高・消込の整合 ― 「残高がおかしい」を見つける

| ID | 論点 | 判定条件 | 限界・注意 |
|---|---|---|---|
| BS | 現預金のマイナス残高 | 口座（補助科目）単位で「期首残高＋当期増減」の月次残高がマイナス | **期首残高の提供が必要**（無い口座はスキップしINFO表示） |
| BS | 売掛金・買掛金等の異常残高 | 補助科目（取引先）単位でマイナス残高（要修正）／取引の無い月が2ヶ月以上続く滞留（要確認） | 補助科目の期首残高が無い取引先は誤検知防止のためスキップ → **その穴を7-1が補完** |
| 7-1 | 経過勘定の未清算差額 | 未払費用・未払金・預り金・立替金・仮払金等で、計上累計と精算累計を突合。精算タイミング（当月/翌月/翌々月）は自動判定。「ある月に一度だけ生じた段差」が解消されないものを差額として検出 | **期首残高が不要**なのが強み。毎月少しずつ動くもの（期首残高の分割返済等）や、未払月数分で説明できる残高は正常として除外 |
| 7-2 | 科目取り違えの可能性 | 7-1の差額と**同額**の仕訳を他の経過勘定から探し、日付・伝票番号・摘要を提示 | 実務担当者が「金額の一致」から科目誤りを見つける手順の再現 |
| 4-1 | 振込手数料の消込漏れ | 売掛金の取引先別残高が振込手数料相当額（110〜1,100円）と一致 | |
| 4-2 | 仮払金・立替金の滞留 | 発生後90日以上精算されていない個別取引 | |
| BS | 仮払金の法人税誤処理 | 摘要に「法人税」を含む仮払金/前渡金仕訳 | 未払法人税等の取崩しに修正すべきケース |
| 前年比BS | 期末残高の前年比較 | 売掛金・買掛金・未払金・借入金の期末残高が前年比±20%（差額20万以上）、または貸借の符号反転 | 前期試算表が必要 |
| 7-3 | 預り金の納付サイクル | 毎月納付されていた預り金（源泉・住民税・社保）の納付だけが2ヶ月以上止まった（警告）／期間中一度も納付が無い（情報・納期特例の注記付き） | |
| 7-4 | 前払費用の按分進行 | 前払費用に計上後、2ヶ月以上取崩し（月次按分）が無い | 決算一括方針なら問題なし（情報レベル） |
| 8-1 | 借入金と支払利息の整合 | 借入金の返済月に支払利息が無い月が2ヶ月以上（役員借入は対象外）／借入金の動きが無いのに利息が続く | |
| 8-2 | 期ズレの兆候 | 月間売上の60%以上が月末3日に集中（情報）／月初3日以内の売上取消・借方売上10万円以上（警告、返品・値引は除外） | |
| 8-3 | 役員貸付金・借入金 | 役員貸付金の発生（認定利息の要否）／役員借入金の100万円超純増 | |
| 8-4 | 減価償却の開始 | 月次償却採用の会社で30万円以上の資産取得後も償却月額が変わらない | 情報レベル |
| 8-5 | 現金残高の過大 | 現金残高100万円超が2ヶ月以上継続（実査の確認喚起） | 期首残高（現金）が必要 |

## C. 税務判断 ― 「税区分・処理が誤っている」を見つける

| ID | 論点 | 判定条件 |
|---|---|---|
| 消費税 | BS科目への課税区分 | 資産・負債科目（現金・売掛金・買掛金・借入金・給与等）の**借方・貸方**に課税区分が付いている |
| 2-1 | 軽減税率の適用漏れ | 摘要が飲食料品（弁当・菓子・パン・牛乳等）なのに10%。外食・会食系や地名（茶屋等）は除外 |
| 2-8 | 新聞の軽減税率 | 紙の新聞代が10%（電子版・デジタルは10%が正しいので除外） |
| 2-2 | 決済手数料の非課税 | カード・EC決済手数料が課税10%（債権譲渡は非課税） |
| 2-3 | 行政手数料・印紙 | 印紙・登記・住民票等が課税10%。店舗名（市役所前店）・駐車場等の文脈は除外 |
| 2-4 | クレカ年会費 | 諸会費でカードブランド名があるのに不課税（本来は課税仕入） |
| 2-5 | 海外ベンダー | 登録不明の海外サービスが課税10% → 適格請求書の登録確認を促す（Google等の登録済み大手は指摘しない） |
| 2-6 | 海外渡航費 | 国際線・海外・外貨等が課税10%（不課税とすべき）。国内空港・都市名は除外 |
| 2-7 | 手当・表彰金 | 精勤・永年勤続・表彰等が課税10%（不課税とすべき）。通勤手当等は除外 |
| 2-9 | 振込手数料の売上返還 | 売掛金回収時に差引かれた手数料（110〜880円）が課税仕入 → 売上対価の返還等へ |
| 2-10 | 受取家賃 | 受取家賃・家賃収入が課税売上（居住用は非課税。事業用は課税でOKの確認喚起） |
| 2-11 | キャッシュバック | 課税売上になっているキャッシュバック・ポイント還元（不課税とすべき） |
| 消費税 | インボイス経過措置 | 摘要にT番号なし等の記載があるのに経過措置の税区分でない |
| 3-1 | 少額資産の特例 | 固定資産に伝票単位10万〜30万円の計上 → 中小企業特例の即時損金算入を提案 |
| 3-2 | 10万円未満の資産計上 | 固定資産科目に10万円未満 → 費用処理すべき |
| 3-3 | 修繕費の資本的支出 | 修繕費に20万円以上 → 資産計上の要否確認（伝票単位で合算、まとめて1件で指摘） |
| 5-1 | 役員給与の定期同額 | 期首3ヶ月目の額を基準に、4ヶ月目以降の変動を検出（期首3ヶ月以内の正規改定は誤検知しない） |
| 5-4 | 交際費との境界 | 会議費2万円超（1人1万円基準）／会議費・福利厚生費の摘要に贈答・ゴルフ等 |
| 5-5 | 源泉徴収漏れ | 支払手数料・外注費5万円超で士業・デザイン・講師等のキーワードがあるのに、同一伝票に預り金（源泉）が無い |
| 2-12 | 消費税額の整合 | 税区分（10%/8%）に対して税額が内税・外税どちらの計算とも乖離（手入力修正ミスの捕捉） |
| 5-6 | 交際費の年間限度額 | 交際費累計が600万円超で接近通知、800万円（中小法人の定額控除限度）超で警告 |

## D. 入力品質・不正リスク ― 「入力そのものの誤り」を見つける

|---|---|---|---|

# 追加を検討すべき論点（提案）

実務チェックシート（吉松工作所の記入例・万代さんのシート）に現れた担当者の視点と、
月次監査の一般的な確認事項から、システム化できるものを優先度順に提案する。

## 優先度A: 実際のチェックシートに前例がある論点

| 提案 | 内容 | 元になった実例 |
|---|---|---|
| A-1 税区分の少数派検知 | 同一科目・同一取引先の仕訳の大多数と**異なる税区分**が少数だけ混じっているものを検出（例: 製品売上高がほぼ10%なのに特定取引先だけ8%） | 記入例「ﾀﾓﾝ分のみ課税8%で計上されていますが、問題ないか」 |
| A-2 諸口・清算勘定の残高 | 諸口（清算勘定）は本来残高ゼロになるべき。月末残高が残っていれば検出 | 記入例「諸口 前期から-1,320円残っている」 |
| A-3 売掛金・買掛金への7-1拡張 | 「計上が無いのに支払だけある」「計上したのに支払が無い」を売掛金・買掛金でも検知（現在7-1は未払金・未払費用等のみ） | 記入例「3月分の仕入計上がされていないか 4/30 2,337,775円支払分」「3月計上260,271円の支払いがない」 |
| A-4 高額未払の長期滞留の格上げ | 金額的重要性が大きい残高（例: 1,000万円超）の滞留は、通常の滞留より強いレベルで指摘 | 記入例「役員退職金 30,000,000円が残っている。支払日未達で問題ないか」 |

## 優先度B: データが揃っており実装が容易な論点 ✅ 実装済み（2-12/7-3/5-6/8-1）

| 提案 | 内容 |
|---|---|
| B-1 消費税額の整合 | 税区分10%なのに消費税額が本体の10/110から乖離している仕訳を検出（仕訳データに税額列あり。手入力修正のミスを捕捉） |
| B-2 預り金の納付サイクル | 源泉所得税・住民税・社会保険の預り金が翌月（納期特例は7月/1月）に取り崩されていない → 納付漏れの早期発見 |
| B-3 交際費の年間限度額の進捗 | 接待交際費の累計が年間800万円（中小法人の損金算入限度）に接近したら通知。5-4で会議費からの振替候補も加味 |
| B-4 借入金と支払利息の整合 | 借入金残高があるのに支払利息の計上が無い月（計上漏れ）／借入金が無いのに利息がある（科目誤り） |

## 優先度C: 決算・税務調査を見据えた論点 ✅ 実装済み（8-2/7-4/8-3/8-4/8-5）

| 提案 | 内容 |
|---|---|
| C-1 決算月前後の期ズレ強化 | 決算月の売上・仕入の月末集中と、翌期初の反転（決算対策の計上・繰延の兆候）。現在の1-2より対象を広げる |
| C-2 前払費用の按分進行 | 年払い保険料・保守料が資産計上されたまま月次償却されていない |
| C-3 役員貸付金・役員借入金の発生 | 役員貸付金の新規発生（認定利息の論点）・役員借入金の急増を通知 |
| C-4 減価償却開始の整合 | 期中に固定資産を取得したのに減価償却費が増えていない（月次償却をしている場合） |
| C-5 現金残高の過大 | 現金商売でないのに現金残高が大きい／長期間動かない（実査・簿外の論点） |

## 提案の狙い

優先度Aは**担当者が実際に手で見つけた指摘のシステム化**であり、「システムは自分たちのチェック観点を学んでいる」という信頼につながる。まずAから実装し、チェックシートとの突合で拾えた/拾えなかったを毎月検証するサイクルを回すことを推奨する。
