# 会計データチェックシステム

会計データ（CSV）をアップロードするだけで、BS・PL・消費税の観点から自動チェックを行うWebアプリケーション。

## 対応会計ソフト
- 弥生会計
- freee
- MoneyForward クラウド会計

## チェック内容

### 貸借対照表（BS）
- 現預金のマイナス残高検出
- 仮払消費税・仮受消費税の期首残高チェック
- 仮払金の長期滞留・法人税誤処理検出
- 売掛金・買掛金の未消込残高確認

### 損益計算書（PL）
- 粗利率の月次変動分析（±2σで異常検出）
- 減価償却費など毎月計上費用の漏れチェック
- 修繕費の資産計上要否判定（20万円以上）
- 雑費・支払手数料の肥大化検出
- 前月比±50%超の異常変動検出

### 消費税
- 資産・負債科目への課税区分誤設定チェック
- インボイス未登録業者への支払い経過措置チェック
- 海外出張費の不課税処理確認

## セットアップ

```powershell
cd backend
python -m pip install fastapi uvicorn pandas openpyxl pdfplumber python-multipart jinja2
python main.py
```

ブラウザで http://localhost:8000 を開く。
